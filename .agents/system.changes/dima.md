## 需求描述

> 开发一个**人员看板**，有入口记录员工的基本信息以及增删改查，支持导入以及记录成本预算——白名单、批量导入。

### 关键功能点
1. **员工基本信息 CRUD** — 增、删、改、查
2. **导入功能** — 支持批量导入员工数据
3. **成本预算** — 记录与员工相关的成本预算
4. **白名单机制** — 控制导入/操作权限或数据范围

## 已确认信息

### 技术栈
- **后端**: Java + Spring Boot
- **数据库**: 关系型数据库（如 MySQL/PostgreSQL）
- **前端**: Vue 或 React

### 员工基本信息字段
- **基础字段**: 姓名、工号、部门、职位、联系方式、入职日期
- **财务字段**: 薪资、银行账号等
- **人事字段**: 教育背景、技能证书、合同期限等
- **个人信息**: 家庭住址、紧急联系人等

### 成本预算
- **范围**: 员工个人维度
- **包含**: 薪资、培训、差旅等个人成本项

### 白名单机制
- **导入白名单**: 控制哪些员工/部门可以被导入
- **操作权限白名单**: 控制谁能查看/编辑成本预算

### 批量导入
- **支持格式**: CSV 文件 + Excel 文件（.xlsx/.xls）
- **导入方式**: 文件上传批量导入
