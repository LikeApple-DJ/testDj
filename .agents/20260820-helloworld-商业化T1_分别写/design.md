# HelloWorld 商业化 T1 设计文档

> 文档编号：20260820-helloworld-商业化T1_分别写  
> 所属仓库：testDj-main  
> 状态：需求澄清 / 待评审  

## 1. 背景与目标

### 1.1 背景

当前 `testDj-main` 与 `testDJnew-main` 两个仓库处于项目早期阶段，需要完成一个入门级别的商业化功能演示：提供三个基础算法/功能接口，并在前端以多 Tab 形式展示执行结果，同时支持结果导出。

### 1.2 目标

- 后端提供 3 个独立接口：`helloworld`、`hash 算法`、`冒泡排序`。
- 前端新增一个页面，包含 3 个 Tab，分别展示上述接口的执行结果。
- 页面提供导出按钮，后端提供导出接口，支持导出当前 Tab 的展示结果。

### 1.3 非目标

- 不做用户权限、登录鉴权。
- 不做复杂的 UI 设计，以功能演示为主。
- 不做持久化存储，结果以实时计算或内存缓存为主。

## 2. 术语说明

| 术语 | 说明 |
|------|------|
| HelloWorld | 返回固定或自定义文本 |
| Hash 算法 | 对输入字符串计算 hash 值（如 MD5 / SHA-256） |
| 冒泡排序 | 对输入数组执行冒泡排序并返回结果 |
| Tab | 前端页面中的标签页，切换显示不同功能结果 |
| 导出 | 将当前 Tab 的结果以文件形式下载 |

## 3. 总体架构


## 4. 后端接口设计

### 4.1 公共约定

- 基础路径：`/api/v1`
- 请求方式：以 `POST` 为主（查询类可用 `GET`）
- 响应格式统一：

```json
{
  "code": 0,
  "message": "ok",
  "data": {}
}
```

### 4.2 HelloWorld 接口

- **路径**：`POST /api/v1/helloworld`
- **说明**：返回问候语，支持自定义名称。

**请求体**：

```json
{
  "name": "World"
}
```

**响应示例**：

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "greeting": "Hello, World!"
  }
}
```

### 4.3 Hash 算法接口

- **路径**：`POST /api/v1/hash`
- **说明**：对输入文本进行 hash 计算，默认 SHA-256，可选 MD5。

**请求体**：

```json
{
  "text": "hello world",
  "algorithm": "SHA-256"
}
```

**响应示例**：

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "input": "hello world",
    "algorithm": "SHA-256",
    "hash": "b94d27b9934d3e08a52e52d7da7dabf..."
  }
}
```

### 4.4 冒泡排序接口

- **路径**：`POST /api/v1/bubble-sort`
- **说明**：接收整数数组，返回冒泡排序后的数组及排序步数。

**请求体**：

```json
{
  "array": [5, 3, 8, 1, 2]
}
```

**响应示例**：

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "input": [5, 3, 8, 1, 2],
    "output": [1, 2, 3, 5, 8],
    "steps": 8
  }
}
```

### 4.5 导出接口

- **路径**：`POST /api/v1/export`
- **说明**：根据当前页面类型和结果数据，生成导出文件。

**请求体**：

```json
{
  "type": "helloworld",
  "data": {
    "greeting": "Hello, World!"
  }
}
```

**响应**：

- 方式一：直接返回文件流（`Content-Disposition: attachment; filename=result.txt`）。
- 方式二：返回文件下载 URL（需额外文件服务）。

**本方案推荐方式一**，简单直接，前端通过 `Blob` 下载。

## 5. 前端页面设计

### 5.1 页面结构

```
+-------------------------------------------+
|            HelloWorld 商业化 T1            |
+-------------------------------------------+
|  [HelloWorld]  [Hash 算法]  [冒泡排序]    |
+-------------------------------------------+
|                                           |
|  Tab 内容区：                              |
|  - 输入参数                                |
|  - 执行按钮                                |
|  - 结果展示                                |
|                                           |
+-------------------------------------------+
|  [导出当前结果]                            |
+-------------------------------------------+
```

### 5.2 各 Tab 内容

#### Tab 1: HelloWorld

- 输入框：name（可选，默认 World）
- 执行按钮
- 结果展示：问候语文本

#### Tab 2: Hash 算法

- 输入框：text
- 下拉选择：algorithm（MD5 / SHA-256）
- 执行按钮
- 结果展示：输入文本、算法、hash 结果

#### Tab 3: 冒泡排序

- 输入框：array（逗号分隔或 JSON 数组）
- 执行按钮
- 结果展示：原始数组、排序后数组、排序步数

### 5.3 导出按钮

- 位置：页面底部或 Tab 内容区右上角。
- 行为：导出当前激活 Tab 的展示结果。
- 文件格式：优先 `txt` 或 `json`。

## 6. 数据流

```
用户打开页面
    │
    ▼
选择 Tab
    │
    ▼
填写参数 → 点击执行
    │
    ▼
前端调用对应后端接口
    │
    ▼
后端计算并返回结果
    │
    ▼
前端渲染结果
    │
    ▼
用户点击导出 → 调用 /api/v1/export → 下载文件
```

## 7. 错误处理

| 场景 | 返回码 | 处理 |
|------|--------|------|
| 参数缺失 | 400 | 前端提示补全参数 |
| 算法不支持 | 400 | 提示可选算法 |
| 数组格式错误 | 400 | 提示正确格式 |
| 服务端异常 | 500 | 友好提示 |
