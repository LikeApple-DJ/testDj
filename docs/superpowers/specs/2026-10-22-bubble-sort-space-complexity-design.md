## 2. 算法描述

冒泡排序是最直观的交换类排序算法：重复遍历待排序列，**逐对比较相邻元素**，若前大后小（升序）则交换，使当前未排序区间内的最大元素像气泡一样“冒”到区间末尾。

### 2.1 流程步骤

1. 设待排区间为 `[0, n)`。
2. 第 `k` 轮（k 从 1 开始）：从位置 0 到位置 `n-k-1`，比较相邻两元素 `a[j]` 与 `a[j+1]`，若 `a[j] > a[j+1]` 则交换。
3. 一轮结束后，区间末尾 `n-k` 位置的元素即为当前最大值，逐步缩短待排区间。
4. 重复 n-1 轮，或当某轮未发生任何交换时提前终止（已有序）。

### 2.2 伪代码（语言无关）

```
算法 bubbleSort(a, n)          # a 为下标 0..n-1 的数组，升序
1. for i = 0 to n-2 do
2.     swapped = false         # 本轮是否发生过交换（优化标志）
3.     for j = 0 to n-i-2 do
4.         if a[j] > a[j+1] then
5.             tmp = a[j]
6.             a[j] = a[j+1]
7.             a[j+1] = tmp
8.             swapped = true
9.         end if
10.    end for
11.    if not swapped then
12.        break               # 已有序，提前退出
13.    end if
14. end for
```

## 3. 复杂度分析

### 3.1 空间复杂度（重点）

**结论：辅助空间复杂度为 O(1)，属原地排序（in-place）。**

推导依据：

| 空间占用项 | 是否随 n 增长 | 说明 |
| --- | --- | --- |
| 交换临时变量 `tmp` | 否 | 固定 1 个标量，O(1) |
| 循环变量 `i`、`j` | 否 | 固定 2 个标量，O(1) |
| 优化标志 `swapped` | 否 | 固定 1 个布尔量 / 标量，O(1) |
| 递归调用栈 | 无 | 采用迭代实现，不存在栈空间 |
| 辅助数组 | 无 | 不分配任何与 n 成正比的额外数组 |

- 除输入数组本身外，所有额外空间均为**常量级**，与输入规模 n 无关，故空间复杂度为 **O(1)**。
- 若采用递归实现冒泡排序，递归深度可达 O(n)，会引入 O(n) 的调用栈空间；因此本设计明确采用**迭代实现**，以保持 O(1) 空间。
- 对比：归并排序需要 O(n) 的临时归并数组；快速排序（递归）均摊 O(log n) 到最坏 O(n) 的栈空间。冒泡排序在空间上是**最节省的一类**。

### 3.2 时间复杂度

| 情形 | 复杂度 | 说明 |
| --- | --- | --- |
| 最好情况 | **O(n)** | 输入已有序，首轮无任何交换即 `swapped=false` 提前退出，仅进行 n-1 次比较 |
| 平均情况 | **O(n²)** | 经典实现比较次数恒为 n(n-1)/2；平均交换次数约 n(n-1)/4（全排列平均逆序对为最大逆序数一半） |
| 最坏情况 | **O(n²)** | 逆序输入，比较与交换均达到最大值 n(n-1)/2 |

推导（最坏情况，无提前退出时）：

- 外循环共 n-1 轮；
- 第 i 轮（i 从 0 起）内层比较次数为 (n-i-1)；
- 总比较次数 = (n-1) + (n-2) + … + 1 = **n(n-1)/2**；
- 最坏情况下每次比较都伴随交换，交换次数同为 **n(n-1)/2**，但交换写操作（3 次赋值）约 3n(n-1)/2。

## 4. 算法性质

| 性质 | 结论 |
| --- | --- |
| 稳定性 | **稳定**：相等元素不交换，相对顺序保持不变 |
| 原地性 | **是**：O(1) 辅助空间，直接修改输入序列 |
| 适用性 | 对基本有序的输入（配合提前退出优化）表现优于其他 O(n²) 算法 |
| 对象 | 可直接用于任意可比类型；仅需支持“比较”与“赋值”操作 |

## 5. 正确性与边界情况

### 5.1 循环不变量论证

- **内循环不变量**：每轮内循环结束后，当前未排序区间 `[0, n-i-1]` 内的最大值位于 `n-i-1` 位。
- **外循环不变量**：第 i 轮结束后，末尾 i+1 个元素已按升序就位。
- 当 i 达 n-2 时，仅剩 1 个元素，天然有序，算法终止。

### 5.2 边界情况

| 输入 | 预期行为 |
| --- | --- |
| 空数组 `n=0` | 直接返回，不进入循环 |
| 单元素 `n=1` | 直接返回 |
| 已有序递增 | 首轮无交换，O(n) 提前退出，结果不变 |
| 逆序递减 | n-1 轮完成，结果升序 |
| 含重复元素 | 稳定性保证相对顺序不变 |
| 含极大/极小值 | 极大值逐轮冒到末尾，极小值逐轮（内层）前移 |

### 5.3 验收标准（供后续实现阶段使用）

- 对任意可比整数序列，输出为升序且元素多重集不变（仅重排）。
- 空间上仅使用常量级额外变量，不分配与 n 成比例的辅助存储。
- 空数组 / 单元素数组安全返回。
- 带重复元素的序列保持稳定顺序。

## 6. 与其他排序算法对比

| 算法 | 时间（最坏/平均/最好） | 空间 | 稳定性 | 原地 |
| --- | --- | --- | --- | --- |
| 冒泡排序 | O(n²) / O(n²) / O(n) | **O(1)** | 稳定 | 是 |
| 插入排序 | O(n²) / O(n²) / O(n) | O(1) | 稳定 | 是 |
| 选择排序 | O(n²) / O(n²) / O(n²) | O(1) | 不稳定 | 是 |
| 快速排序 | O(n²) / O(n log n) / O(n log n) | O(log n)~O(n) | 不稳定 | 是 |
| 归并排序 | O(n log n) / O(n log n) / O(n log n) | O(n) | 稳定 | 否 |

结论：冒泡排序的**空间占用与插入/选择排序并列最优（O(1)）**，但在时间上逊于 O(n log n) 算法，适合小规模、基本有序或严格受限内存场景。

## 8. 结论

冒泡排序通过反复交换相邻逆序对完成排序，其核心价值点在**空间复杂度 O(1)**：除输入外仅需常量级临时变量，为真正的原地排序。其时间代价为 O(n²)（最好 O(n)），且稳定。本设计明确了伪代码、复杂度推导、正确性边界与后续实现接口，为下一步编写实现计划提供完整依据。
