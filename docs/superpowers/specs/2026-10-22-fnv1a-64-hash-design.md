# 通用哈希函数 FNV-1a 64 位 — 设计文档

- 日期：2026-10-22
- 状态：已确认设计
- 用途：哈希表用通用哈希函数，Python 实现

## 1. 目标

提供一个零依赖、确定性、跨进程一致的通用哈希函数，用于哈希表索引 / 查找 / 种子生成。输入支持 `str` 和 `bytes`，对于表示相同字节序列的 `str` 与 `bytes`，输出必须一致。

## 2. 架构与组件

单一纯函数，无全局状态、无副作用：

```
fnv1a_64(data) -> int
```

- `data`：`str`（内部按 UTF-8 编码）或 `bytes`。
- 返回：`0` 到 `2^64 - 1` 的无符号 64 位整数。

### 算法常量

- FNV offset basis（64 位）：`14695981039346656037`
- FNV prime（64 位）：`1099511628211`

### 处理流程（每字节）

```
hash = offset_basis
for each byte in data_bytes:
    hash ^= byte
    hash = (hash * prime) & 0xFFFFFFFFFFFFFFFF
return hash
```

## 3. 数据流

1. 调用方传入 `str` 或 `bytes`。
2. 若为 `str`，先 `data.encode("utf-8")` 得到字节序列；若为 `bytes` 直接使用。
3. 逐字节做 FNV-1a 迭代，并用 `& 0xFFFFFFFFFFFFFFFF` 截断到 64 位。
4. 返回无符号整数结果。

关键不变式：`fnv1a_64(some_str) == fnv1a_64(some_str.encode("utf-8"))`。

## 4. 错误处理

- 输入既非 `str` 也非 `bytes` 时，抛出 `TypeError`，错误信息明确提示仅支持 `str` 或 `bytes`。
- 不静默转换其他类型，避免意外行为。

## 5. 测试

- 空输入 `b""` 的官方 FNV-1a 64 位参考值（`0xcbf29ce484222325`）。
- 经典字符串（如 `b"foobar"`）的官方参考值。
- `str` 与 `bytes` 等价性测试，含非 ASCII（如中文）。
- 非法输入（如 `int`、`None`、`list`）抛出 `TypeError`。
- 输出范围检查：结果落在 `[0, 2^64 - 1]`。

## 6. 范围与非目标

- 仅实现通用哈希：本函数不具备密码学强度，不得用于安全/完整性校验场景。
- 不引入第三方依赖、不提供流式（分块）接口（哈希表键通常较短，YAGNI）。
