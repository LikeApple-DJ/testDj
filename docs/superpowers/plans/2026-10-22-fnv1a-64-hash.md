**Goal:** 实现一个零依赖、确定性的通用哈希函数 `fnv1a_64(data) -> int`，支持 `str` 和 `bytes` 输入，用于哈希表索引/查找。

**Architecture:** 单一纯函数，采用 FNV-1a 64 位算法；`str` 内部按 UTF-8 编码后与等价 `bytes` 得到相同结果，输出为 0~2^64-1 无符号整数。

**Tech Stack:** Python 3（仅标准库；测试用标准库 `unittest`，兼容 `pytest`）

## Global Constraints

- 语言：Python 3
- 零第三方依赖
- `str` 与等价 `bytes` 输出一致（`fnv1a_64(s) == fnv1a_64(s.encode("utf-8"))`）
- 非 `str`/`bytes` 输入抛 `TypeError`
- 输出范围 `[0, 2^64 - 1]`
- 非密码学哈希，不得用于安全/完整性场景

```python
_FNV_OFFSET_BASIS_64 = 14695981039346656037
_FNV_PRIME_64 = 1099511628211
_MASK_64 = 0xFFFFFFFFFFFFFFFF


def fnv1a_64(data):
    """FNV-1a 64 位通用哈希。

    支持 str 与 bytes；str 按 UTF-8 编码。返回 0~2^64-1 的无符号整数。
    非密码学哈希，不得用于安全/完整性校验。
    """
    if isinstance(data, str):
        data = data.encode("utf-8")
    elif not isinstance(data, bytes):
        raise TypeError(
            "fnv1a_64 仅支持 str 或 bytes，收到: {}".format(type(data).__name__)
        )

    h = _FNV_OFFSET_BASIS_64
    for b in data:
        h ^= b
        h = (h * _FNV_PRIME_64) & _MASK_64
    return h
```
