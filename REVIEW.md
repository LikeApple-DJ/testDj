# Project Review Profile

## Project Type
Documentation / article repository. Primary artifact: Markdown articles.

## Review Gates
- **Content accuracy**: factual claims must be verifiable or cited.
- **Word count compliance**: articles must meet stated length requirements (±10%).
- **Structure quality**: clear headings, logical flow, consistent formatting.
- **Language quality**: grammar, spelling, punctuation correctness in Chinese.

## Changed Crates / Modules
- `docs/` — Markdown articles, no code dependencies.

## Skipped Checks
- No compile, test, lint, or CI steps apply to this project.
